## Accepted authentication behavior

- The initial owner is provisioned and active; additional users are managed manually.
- No separate aiMoney password. An authorized email receives an 8-digit code.
- Codes expire after ten minutes, work once, and allow at most five verification attempts.
- Requests are limited per email, client IP and globally. Unknown or disabled users
  receive the same generic response and no email.
- Sessions last 12 hours, or 30 days with the explicit personal-device option.
  Cookies are Secure, HttpOnly and host-only; sign-out revokes the server session.
- Disabling a user blocks existing sessions on the next protected request.
- All authorized users currently share portfolio records and application controls.
  Roles and separate portfolios are future work, not implemented access boundaries.
- Private credentials stay outside Git and image layers, in owner-only files on
  encrypted storage. The API and database have no publicly published ports.
