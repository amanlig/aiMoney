# Architecture icons

AWS EC2, Route 53, EBS and S3 service icons and Docker, PostgreSQL and Caddy icons
were obtained from [Diagrams resources](https://github.com/mingrammer/diagrams/tree/master/resources).
The Diagrams project license is retained in `DIAGRAMS-LICENSE`; underlying product
marks belong to their owners.

React and FastAPI logos come from [Devicon](https://github.com/devicons/devicon),
with its license retained in `DEVICON-LICENSE`.

Questrade, Yahoo and OpenAI use text badges in the diagram rather than official
logos. The browser and Elastic IP symbols are original SVG shapes.
The renderer embeds all image data so the exported SVG requires no network access.
